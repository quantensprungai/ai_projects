# Altfragen — Klausur ESF (2. Sem., Natalie)

*Aus `Altfragen_Klausur Natalie 2.Sem.docx` — gemerkte Aufgabentypen, **hohe Priorität**.*

## Aufgaben (wie in der Klausur)

1. **ESF erklären** + Einzelbestandteile der Definition (vom Anfang der Vorlesung)
2. **Induktion & Deduktion** — jeweils **5 Charakteristika**
3. **Pearson-Korrelationskoeffizient** — wann / wofür? (Ankreuzaufgabe)
4. **SPIDER-Schema** erklären + eigene Forschungsfrage daraus formulieren
5. **Gütekriterien qualitativer Forschung** (4 Stück) nennen und beschreiben
6. **Streuungsmaße**, positive/negative **Korrelation** aus Diagramm ablesen
7. **Anwendungsaufgabe:** Outcomes anhand von **p-Werten** erklären
8. **Text** zu quantitativer Forschung schreiben
9. **Kernunterschiede** qualitativ vs. quantitativ
10. **PICOT-Schema** erklären + eigene Forschungsfrage
11. Unterschied **wissenschaftliche vs. statistische Hypothese**
12. **Dichotome Variablen** (?) — Zuordnung/Konzept

## Prüfungs-Schwerpunkte (Kurz)

| Thema | Typ |
|-------|-----|
| Definitionen Einführung | Schreiben |
| Deduktion / Induktion | Listen (5+5) |
| PICO / PICOT / SPIDER | Schema + eigene Frage |
| Qual: Gütekriterien (4) | Nennen + beschreiben |
| Quant: r, Streuung, Diagramm | Zuordnen / ablesen |
| p-Werte | Interpretieren |
| Hypothesen (wiss. vs. stat.) | Unterscheiden |
| Qual vs. Quant | Kernunterschiede |
