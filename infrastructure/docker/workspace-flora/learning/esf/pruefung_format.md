# ESF – Prüfungsformat (Flora)

**Stand:** Klärung aus Modulvorgabe

| Parameter | Wert |
|-----------|------|
| Dauer | 60–90 Minuten |
| Aufgaben | ca. 20–25 |
| Rechenaufgaben | **1–3** (Kopfrechnen, **ohne Taschenrechner**) |
| Schwerpunkt | Verstehen, Zuordnen, Interpretieren, Anwenden auf Fälle |

## Was trainieren

- Begriffe sauber definieren (Gütekriterien, Operationalisierung, Stichprobe, …)
- Forschungsfrage vs. Hypothese vs. Operationalisierung unterscheiden
- Qualitative Schritte (Design → Erhebung → Kodierung → Kategorien)
- Quantitativ: **Skalenniveau**, **deskriptiv interpretieren**, **p-Wert/Fehlerarten** — nicht SPSS
- Studiendesigns erkennen (Querschnitt, Längsschnitt, Experiment light)
- Mixed Methods: wann sinnvoll, nicht Details auswendig

## Kopfrechnen (realistisch in der Prüfung)

Erlaubt / üblich:

- Mittelwert aus 3–5 ganzen Zahlen
- Median bei ungerader Anzahl (5 Werte sortieren)
- Einfache Prozente (z. B. 10 von 40 = 25 %)
- Modus ablesen
- „Welche Skala?“ — keine Rechnung

Nicht üblich ohne TR:

- SD mit Dezimalstellen ausrechnen
- t-Tests, Chi², Regression
- Logarithmen, Wurzeln

## Lernplan-Anpassung

- **Woche 2, Tag 10–11:** 2–3 Kopfrechn-Übungen + viele Interpretations-Szenarien
- **Tag 14:** `pruefung_simulation.md` unter Zeitdruck (75 Min), danach Musterlösungen

Sage/Hermes: bei Prüfungsfragen dieses Format als Rahmen nutzen — keine Panik, kein „du musst alles können“.
